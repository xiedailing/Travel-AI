# B. 收藏缺失狀態補圖設計

## 範圍

在既有 Figma `B. 收藏` section 中補齊六張畫面，沿用現有 393 px 行動版框架、元件、字體、色彩與命名規則。此次不製作 B3-07、B3-08，也不修改既有主流程。

## 新增畫面

1. `B1-04A_收藏列表_載入中`
   - 由收藏列表預設狀態延伸。
   - 保留 Header、篩選列與底部導覽。
   - CardList 改為 FolderCard 骨架載入狀態，避免使用全頁 Spinner。

2. `B3-03A_景點詳情_加入行程Sheet_未選取`
   - 由現有加入行程 Sheet 延伸。
   - 所有 TripListItem 為 Default、已選數量為 0、確認按鈕 Disabled。

3. `B3-06_景點詳情_建立新行程Sheet`
   - 由 B3 景點詳情作為背景，使用 Scrim 與 Bottom Sheet。
   - 將 `C1-1 · 我的行程_新增旅程` 的表單內容移植到可捲動 Sheet：封面預覽、色票、行程名稱、目的地、旅行日期。
   - 沿用 `行程卡片_Cover`、`ColorSwatch`、`TextField`、`Button/Primary`。
   - Sheet 高度約 720–760 px，底部建立 CTA 固定可見。

4. `B4-10A_手動匯入_收藏提交中`
   - 由多個結果調整選取狀態延伸。
   - 保留選擇結果，CTA 切換 Loading／Disabled，避免重複提交。

5. `B4-10B_手動匯入_多個結果_全部未選取`
   - 所有 ResultCard 未選取，顯示已選 0 項。
   - 收藏 CTA Disabled，保留全選入口。

6. `B4-E04_手動匯入_AI辨識失敗_系統錯誤`
   - 與無效連結、找不到景點分離。
   - 顯示系統／網路辨識失敗訊息與重新辨識操作。

## 排列與命名

- B1 新狀態放在 B1 第一排相關畫面旁。
- B3 新狀態放在 B3-03 後方，B3-06 放在加入行程流程末端。
- B4-10A／10B 放在 B4-10 附近；B4-E04 放在 E 系列錯誤列。
- 命名完全依照目前 `模組-序號_功能_狀態` 格式。

## 實作原則

- 優先 clone 最接近的既有 Frame，保留元件連結與樣式。
- 不建立新的 Main Component；以既有 instance variant／property 覆寫為主。
- 每一張新增畫面完成後檢查 Clip content、文字裁切、Disabled／Loading 狀態與 44 px 觸控尺寸。
- 最後以結構檢查與畫面截圖驗證六張新增畫面。

## 驗收條件

- 六張 Frame 都存在於 `B. 收藏`，名稱唯一且可排序。
- B3-06 使用 C1-1 的既有表單元件，不是整張手機畫面縮放。
- 未選取狀態不可送出；提交中不可重複點擊；系統錯誤可重新嘗試。
- 無裁切、重疊、錯誤字型或殘留 placeholder。
