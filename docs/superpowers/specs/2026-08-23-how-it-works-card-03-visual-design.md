# How It Works 第三張卡片示意圖設計

## 目標

為 Figma 檔案中「03 HOW IT WORKS｜三步完成規劃」區塊的第三張卡片製作新版示意圖，使其視覺語言與前兩張一致，同時保留現有卡片不變。

## 核准方向

採用「行程完成面板」：以橫式、產品 UI 風格呈現已完成的每日行程，包含三個時間節點、地點縮圖、完成狀態及小型出發符號。畫面不使用真人手部或寫實手機照片。

## 圖像規格

- 生成尺寸：828 × 340 px。
- Figma 顯示尺寸：414 × 170 px。
- 背景：暖白色。
- 色彩：靛藍為主，搭配鼠尾草綠與少量陶土橘。
- 風格：乾淨的產品 UI 示意、圓角卡片、柔和陰影，與第一、第二張卡片一致。
- 內容：三個簡化行程節點、完成勾選、小型飛機或出發符號。
- 避免：真人、手持手機、可辨識品牌文字、亂碼、浮水印、過度寫實材質。

## Figma 操作

1. 保留節點 `3446:550`「03 確認出發｜Station」不變。
2. 複製完整第三張卡片，而非只複製圖片圖層。
3. 將副本放在原卡片右側的空白畫布，保持合理間距，不覆蓋現有設計。
4. 在副本中移除或隱藏原本「拿手機」視覺，改放新版橫式示意圖。
5. 保留副本中的標題、說明、步驟標籤、圓角與邊框樣式。
6. 完成後以 Figma 截圖驗證：原卡片未變、副本未重疊、圖片沒有拉伸或裁掉主要資訊。

## 驗收條件

- 原第三張卡片完整保留。
- 旁邊有一張可獨立比較的完整副本。
- 新圖在副本內以 414 × 170 px 呈現。
- 新圖與前兩張的 UI 示意風格、配色與視覺密度協調。
- 沒有錯字、AI 亂碼、浮水印或不必要的照片元素。
