# Slide 14 — Visual Identity & UI System 設計規格

## 目標

用單頁說明 Trova 的品牌識別如何延伸至產品介面，並讓觀眾理解視覺系統如何區分「使用者操作」與「AI 協助」。此頁不是完整 Style Guide 清單，而是品牌邏輯與 UI 證據的精簡摘要。

## 核心訊息

視覺不只建立 Trova 的旅行品牌感，也以暖陶土色與靛藍色清楚區分人與 AI 的角色。

## 素材來源

- Logo：`assets/LOGO/Frame.png`
- Style Guide：Figma 節點 `3008:5370`
- 字體：Noto Sans TC
- 代表元件依 Figma Style Guide 的 Primary Button、行程卡片與 AI 建議卡重製為簡報展示樣本。

## 內容結構

### 左側：品牌識別

- 放大呈現 Trova Logo。
- 一句 Logo 理念：定位標記代表旅行地點，星芒代表 AI 協助探索與整理。
- 一句品牌延伸：定位旅行靈感，透過 AI 將它整理成可執行的旅程。

### 右上：核心色彩

只呈現五個代表色，不展示完整 token 表：

- Cream `#FBFAF7`：頁面背景與旅行氛圍。
- Terracotta `#8D432A`：使用者操作與主要 CTA。
- Indigo `#4A5FC7`：AI 功能與 AI 提示。
- Warm Black `#2E2A24`：主要文字。
- Neutral `#6B6357`：次要資訊。

以 Terracotta 與 Indigo 的角色分工為主要敘事，其他顏色作為支援。

### 右中：Typography

- 顯示 Noto Sans TC 字體名稱。
- 以 Bold 與 Medium 兩層示範資訊層級。
- 文字說明：清楚、友善，適合資訊密集的旅行規劃介面。

### 右下：代表元件

平行呈現三個小型 UI 樣本：

1. Primary Button：一般使用者操作。
2. 行程卡片：行程資訊承載。
3. AI 建議卡：AI 介入與提醒。

元件只展示足以辨認的核心形態，不完整複製所有狀態或規格。

## 視覺版型

- 採 35%／65% 左右分割的編輯式構圖。
- 左側 Logo 區留有呼吸空間，作為主要視覺焦點。
- 右側以色彩、字體、元件形成由上至下的設計證據。
- 不使用四宮格 Feature Card 或密集 Style Guide 表格。
- 延續既有簡報的暖米色背景、襯線大標題與細線分隔。
- Terracotta 與 Indigo 必須成為最明顯的色彩對照。

## 標題與文案

- Eyebrow：`Visual Identity & UI System`
- 主標題：`視覺不只建立品牌，也區分人與 AI 的角色`
- Logo 理念：`定位旅行靈感，透過 AI 將它整理成可執行的旅程。`
- 色彩原則：`暖陶土色承載使用者操作，靛藍色專門標示 AI 介入。`

## 範圍限制

- 不列出完整 Neutral 色階、Border token 或所有元件狀態。
- 不呈現候補、備案或降雨建議元件。
- 不獨立製作 Logo 設計歷程頁。
- 不加入 Prototype 連結或 QR Code。
- 不修改 Figma Style Guide。
